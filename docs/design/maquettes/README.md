# Maquettes Fantrail

Copie de secours des maquettes du canevas Claude Design (DA « Dossard » côté joueur, shadcn/ui côté admin).

La version de référence, à ouvrir et commenter, est le canevas : https://claude.ai/artifact/AsgVgqAjnuKeq9iYXT45M4

Chaque fichier `.dc.html` est un écran, `canvas.json` décrit leur disposition. Ces fichiers ne s'affichent correctement que dans le canevas.
